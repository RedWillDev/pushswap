# Push_swap — modules de Julien

Cette archive conserve les modules attribués à Julien dans le ZIP source :

- `operations.c` : opérations sur les deux piles.
- `medium.c` : stratégie Medium par chunks.
- `push_swap.h` : structures et déclarations partagées nécessaires à ces modules.

Le parsing, le point d’entrée et les autres stratégies ne sont pas inclus. Cette archive contient donc les modules de Julien, mais ne constitue pas un projet complet et autonome à compiler.
